The cause was ours: our own speed-up set the card's typing speed to **0**, and zero does not mean "fast" — it makes the game take a different branch of its own code, one that never raises the "plate finished" flag the card waits for. It is now 1: the game stays on its own branch and does everything it did, just faster. The whole transition takes about 0.7s instead of 3s.<br>• **Every disc sector we hand the game is now byte-identical to the original disc.** The 280 bytes of error detection and correction were being filled with zeros, and the end-of-file marker on each file's last sector was missing. It is now counted.<br>• **Saves from an older version are recovered automatically** (#27). If your games were inside `card1.mcd` and there were no `save*.sav` files, the card mounted blank and the game said there was no save — while your data sat right next to it unread. It is now converted, once, without ever touching the old file or overwriting an existing save.<br>• **New launcher tool: PORT .MCD.** Bring a save from an emulator, a real memory card or an older version. Keyboard and mouse count as one device, so the same action can be a key or a click. Seven separate faults were fixed on the way: the option would not change when clicked, the previous binding stayed alive beside the new one, and arrows and WASD were wired to the directions inside the engine itself — they are yours now.<br>• **A 15-second countdown confirms each new binding** and puts the old one back if you say nothing, so a key you cannot press again never locks you out.<br>• **Clicking a tab in the menu goes to that tab** (video, audio, controls) instead of moving one step.<br>• **40 achievements of our own**, off by default. They exist so there are achievements today without waiting on anyone, and so the whole chain — detect, notify, save — is already tested for the day the RetroAchievements client is approved. They do not count towards a RetroAchievements profile and do not pretend to. Story milestones are recognised by the item each one hands you, and every item number comes from the game's own name table, not from guesswork.<br>• **Hotscrock is credited** as the author of the 137 RetroAchievements achievements for this game, used with his permission.<br>• **Sony's BIOS: 99% less on your disk.** `Engine/datos_kernel.bin` carried the whole 512 KB ROM; it now carries only the 147 blocks the port actually needs — 38 KB, 7.2% of the ROM.
