# Licence

This tab is a port of the **Digimon World 3 Randomizer** by **markisha64**,
published under the MIT licence:

<https://github.com/markisha64/dmw3-randomizer>

The algorithms, the option set and the constants are his work. What was written
here is the C reimplementation that applies the result as a mod instead of
rebuilding a disc image.

## Why his LICENSE.md is not reproduced here

His repository's `LICENSE.md` is the MIT text with GitHub's template header left
unedited, so its copyright line reads *"Copyright (c) 2011-2017 GitHub Inc."*.
Shipping that file inside this folder would put the wrong holder's name on his
work, so it is linked instead of copied.
