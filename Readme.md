# Digimon World 3 — Port nativo de PC / Native PC Port

> **ES:** Digimon World 2003 corriendo como un programa de PC: sin BIOS, sin
> imagen de disco y sin ficheros de consola. El modelo es el port de PC de
> Digimon World 1, no un emulador bien empaquetado.
>
> **EN:** Digimon World 2003 running as a native PC program: no BIOS, no disc
> image, no console files. Modeled after the Digimon World 1 PC port, not a
> repackaged emulator.
